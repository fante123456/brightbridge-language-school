# BrightBridge Language School

A website for BrightBridge Language School, a **fictional** language school in Manchester, built for **MX AI Academy Challenge 5**. The school, teachers, courses, prices and opening hours are all invented for this exercise.

**Live site:** https://brightbridge.ammar-rajabi.com

## Pages

- **Home** – hero, popular courses, why choose us, student voices, free trial lesson
- **About** – story, teaching philosophy, teachers, learning values
- **Courses** – 8 courses with level (CEFR A1–C1), duration and format, language and level filters, CEFR levels explained
- **Student Life** – classroom atmosphere, online learning, group activities, student support, learning resources
- **Contact** – address, phone, email, opening hours, map link and a free trial lesson form (demo only, no data is sent)

## Tech

- [Next.js](https://nextjs.org) (App Router, TypeScript), exported as a static site
- [Tailwind CSS](https://tailwindcss.com) v4
- `next/font` (Nunito + Atkinson Hyperlegible), `next/image` with Unsplash photos, lucide-react icons

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in ./out
```
